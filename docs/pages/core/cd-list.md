# 倒数日列表（首页）

> 应用冷启动入口。展示全部倒数日，按距离远近分组，提供添加、切换版式、切换排序、进入设置四个出口。
> 实现：`src/pages/cd-list/cd-list.ux`（685 行） · 数据层：`src/common/countdown.js`

## 1. 页面职责

| 职责 | 说明 |
|---|---|
| 展示 | 全部倒数日按状态分组渲染，逐条给出剩余天数与进度条 |
| 入口 | 「＋添加」新建、条目点击进入编辑、长按弹出操作菜单 |
| 版式 | 两套版式可切换：`list`（简单列表，默认）/ `hero`（沉浸大数字） |
| 排序 | 两套排序可切换：`recent`（按时间，默认）/ `name`（按名称） |
| 出口 | 右上角进入设置页 `/pages/settings` |

**不做的事**：本页不写入业务数据，只负责读取、排序、渲染与跳转。增删改都发生在 `cd-edit`。

## 2. 路由与入口

| 项 | 值 |
|---|---|
| 路由 | `pages/cd-list` |
| 文件 | `src/pages/cd-list/cd-list.ux` |
| 启动页 | 是（`manifest.router.entry`） |
| 入参 | 无（不读 `route.query`） |
| 前置依赖 | `storage` 中的列表数据、`cd_layout` 版式偏好 |

`onShow` 每次回到本页都会重新 `loadList()`，因此从 `cd-edit` 返回后列表立刻反映最新数据，不依赖跨页消息。

## 3. 页面结构

```
scroll (page, scroll-y)
├── 头部
│   ├── 标题「倒数日」
│   ├── toggleSort        「按时间」/「按名称」
│   ├── toggleLayout      「列表」/「大字」（toolbar-link）
│   └── goSettings        设置
├── 已结束分组（item.showDivider 为真的首条前插入分隔线 + 「已结束」标签）
├── 版式 A · list（layout !== 'hero'）
│   └── ls-row × N   两行一条：名称 / 日期行 + 剩余天数
└── 版式 B · hero（layout === 'hero'）
    └── hero-card × N  竖版居中，超大数字
```

空态：`还没有倒数日` / `点下方按钮添加一个` / `＋添加`。

## 4. 数据与存储

| key | 类型 | 写入方 | 说明 |
|---|---|---|---|
| 列表数据 | Array | `cd-edit` 保存 | 每条含 id、名称、目标日期、颜色、首页显示开关等 |
| `cd_layout` | `'list'` \| `'hero'` | 本页 `toggleLayout` | 版式偏好，本地持久化，下次启动沿用 |
| `cd_edit_id` | string | 本页 `openForm` | 传入编辑页的条目 id；新建时留空 |

读取容错：`cd_layout` 非法值一律回落 `list`（`self.layout = (v === "hero") ? "hero" : "list"`）；storage 为空时按空列表渲染空态，不抛错。

## 5. 交互规则

| 手势 | 位置 | 行为 |
|---|---|---|
| 点击 | 「＋添加」 | `startAdd()` → 清空 `cd_edit_id` → 进入 `cd-edit` |
| 点击 | 条目 | `openForm(item)` → 写 `cd_edit_id` → 进入 `cd-edit` |
| 长按 | 条目 | `goMenu(item)` → 弹出操作菜单（编辑 / 删除 / 首页显示） |
| 点击 | 排序链接 | `toggleSort()` → 文案在「按时间」「按名称」间切换 |
| 点击 | 版式链接 | `toggleLayout()` → 文案在「列表」「大字」间切换 |
| 点击 | 「设置」 | `goSettings()` → `/pages/settings` |
| 下拉 | 列表区 | 不触发刷新（数据全在本地，无需网络） |

## 6. 状态与边界

| 状态 | 表现 |
|---|---|
| 空列表 | 空态三行文案，添加按钮仍可点 |
| 今日到期 | `item.isToday` 为真，`list` 版式显示「今天」，`hero` 版式显示「就是今天」 |
| 已过期 | 归入「已结束」分组，排在末尾，天数不计负数 |
| 名称超长 | 单行省略（`lines` 限制），不换行撑破卡片 |
| 无首页显示 | 若条目关闭「首页显示」，不在本页出现（筛选发生在数据层） |
| 主题切换后返回 | `onShow` 重读主题，颜色即时刷新 |

## 7. 平台约束（Vela 手环）

1. **必须整页包在 `<scroll>` 里**，竖屏高度固定 ~490px，条目多于一屏时靠滚动而非压缩行高。
2. 进度条用两层 `div`（`cd-bar-track` / `cd-bar-fill`）实现，不引入 canvas 或图片。
3. 长按菜单走系统级 `contextmenu`，手环无右键，只认长按。
4. 文字尺寸全部由 `loadLayout()` 按屏幕宽度换算，禁止写死 px —— 不同机型画布宽度不同（212×520 与 192×490 都要能用）。

## 8. 验收要点

- [ ] 冷启动直达本页，空库时显示空态而非白屏
- [ ] 添加一条 3 天后的倒数日，返回后列表出现且天数正确
- [ ] 今日到期条目显示「今天」/「就是今天」
- [ ] 切换版式后杀进程重启，版式仍是上次选的
- [ ] 切换排序后名称序与时间序确实不同
- [ ] 条目数超过一屏时可滚动到底，最后一条完整可见
- [ ] 长按条目能弹出菜单，菜单三项都可用
