# 名称输入（九宫格）

> 倒数日名称的专用输入页。手环没有软键盘，文本输入必须自带输入界面，本页承担这一职责。
> 实现：`src/pages/cd-name/cd-name.ux`（235 行） · 对应组件：`input-method`

## 1. 页面职责

| 职责 | 说明 |
|---|---|
| 输入 | 九宫格键盘（拼音 / 数字 / 符号），逐字上屏 |
| 回传 | 保存时写 `cd_edit_name`，由 `cd-edit` 的 `drainName()` 消费 |
| 边界 | 长度上限由页面限制，超出不再上屏 |

**不写业务数据**：本页只负责把字符串交回上一页，落库仍由 `cd-edit` 的保存动作完成。

## 2. 路由与入口

| 项 | 值 |
|---|---|
| 路由 | `pages/cd-name` |
| 文件 | `src/pages/cd-name/cd-name.ux` |
| 入参 | 当前名称（`cd-edit` 跳转时带过去，用于二次编辑继续加字） |
| 上游 | `cd-edit` 的名称行 |
| 下游 | 返回 `cd-edit` |

## 3. 页面结构

```
div.page（无 scroll：键盘必须常驻可见，整页高度锁定）
├── 页头胶囊     后退 + 标题
├── 已输入区     当前字符串，超出宽度时尾部滚动/截断
├── input-method 九宫格组件
└── 「保存」
```

页面**刻意不放入 scroll**：一旦整页可滚，手指在键盘上滑动会把键盘滚出视口，输入立刻不可用。

## 4. 数据与存储

| key | 类型 | 写入时机 | 说明 |
|---|---|---|---|
| `cd_edit_name` | string | 点击保存 | 供 `cd-edit` 读取的暂存值 |

键名以 `cd_edit_` 为前缀，表示「编辑态暂存」，与业务列表数据分开。`cd-edit.onShow` 读到后立刻清键，确保取消输入不会在下次编辑时复活。

## 5. 交互规则

| 手势 | 位置 | 行为 |
|---|---|---|
| 点击 | 字母/数字键 | `onChar(ch)` → 追加到当前串 |
| 点击 | 删除键 | `onDel()` → 删末字符；空串时无响应 |
| 点击 | 保存 | `save()` → 写 `cd_edit_name` → `goBack()` |
| 点击 | 返回 | `goBack()` → 直接退回，不写 `cd_edit_name` |

## 6. 状态与边界

| 状态 | 表现 |
|---|---|
| 空串保存 | 允许返回，由 `cd-edit` 的保存校验统一拦「名称为空」 |
| 达到长度上限 | 后续按键不响应，不弹提示（手环空间有限） |
| 超出显示宽度 | 已输入区尾部滚动，头部保留 |
| 从编辑页二次进入 | 带上原名称，可继续追加或删除 |

## 7. 平台约束（Vela 手环）

1. 无系统软键盘，`<input>` 不可用，必须自带 `input-method` 组件。
2. 页面高度固定一屏，键盘区占大头，已输入区只能分到一行。
3. 键位尺寸按屏幕宽换算，192 与 212 两种画布都要可用。
4. 输入法词库只读本地词库，不联网 —— 与 `diag` 页的「词库」诊断项对应。

## 8. 验收要点

- [ ] 逐字输入中文，已输入区正确显示
- [ ] 删除键能逐字回退，空串时点击不崩溃
- [ ] 保存后回到编辑页，名称行立刻显示新值
- [ ] 按返回不保存，编辑页名称保持原样
- [ ] 连续输入超过一屏宽度，显示不撑破布局
