# 昵称

> 设置用户昵称。与倒数日名称不同，昵称是全局个人信息，只影响展示（如列表问候），不参与业务逻辑。
> 实现：`src/pages/nickname/nickname.ux`（208 行）

## 1. 页面职责

| 职责 | 说明 |
|---|---|
| 输入 | 九宫格输入昵称，与 `cd-name` 同一套输入组件 |
| 保存 | 写 `cd_nick`，返回设置页 |
| 回显 | 进入时带出已有昵称，可续写或删除 |

单屏页：一行说明 + 输入区 + 保存按钮，一屏装得下，不滚动。

## 2. 路由与入口

| 项 | 值 |
|---|---|
| 路由 | `pages/nickname` |
| 文件 | `src/pages/nickname/nickname.ux` |
| 入参 | 无（昵称直接从 `cd_nick` 读） |
| 上游 | 设置页「昵称」 |
| 下游 | 返回设置页 |

## 3. 页面结构

```
div.page（单屏，无 scroll）
├── 页头胶囊  后退 + 「设置昵称」
├── 输入区    「输入昵称」占位 / 当前值
└── input-method 九宫格 + 「保存」
```

`onReady` 里读取 `cd_nick` 并回填，确保先渲染骨架再填值，避免长昵称把布局撑开一帧。

## 4. 数据与存储

| key | 类型 | 说明 |
|---|---|---|
| `cd_nick` | string | 昵称正文，全局唯一存储键；设置页读它渲染右侧文案 |

与 `cd-name` 的区别：`cd-name` 写的是 `cd_edit_name`（编辑态暂存，用完即清），本页写的是持久昵称，不清理。

## 5. 交互规则

| 手势 | 位置 | 行为 |
|---|---|---|
| 点击 | 字母/数字键 | `onChar(ch)` 追加 |
| 点击 | 删除键 | `onDel()` 删末字符 |
| 点击 | 保存 | `save()` → 写 `cd_nick` → `goBack()` |
| 点击 | 返回 | `goBack()` 不保存 |

## 6. 状态与边界

| 状态 | 表现 |
|---|---|
| 从未设置 | 输入区显示占位「输入昵称」，设置页显示「未设置」 |
| 保存空串 | 等同清空昵称，设置页回落「未设置」 |
| 超长昵称 | 受输入组件长度上限约束，超出不响应；输入区尾部滚动 |
| 重复进入 | 带出已有昵称，可继续编辑 |

## 7. 平台约束（Vela 手环）

1. 单屏页，不滚动 —— 输入页一旦可滚，滑动键盘会把键盘滚出视口。
2. 无系统软键盘，文本输入统一走 `input-method` 组件，与 `cd-name` 共用。
3. 页头胶囊与 `theme` / `settings` / `cd-list` 同构。
4. 昵称不联网同步，纯本地存储。

## 8. 验收要点

- [ ] 首次进入显示占位符「输入昵称」
- [ ] 输入并保存后，设置页右侧立刻显示昵称
- [ ] 再次进入能带出已保存的昵称
- [ ] 清空后保存，设置页恢复「未设置」
- [ ] 切换主题后本页配色同步
