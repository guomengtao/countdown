# 主题配色

> 11 套配色的选择页。选中即全局生效，所有页面通过 `data/theme.js` 读取当前主题。
> 实现：`src/pages/theme/theme.ux`（157 行） · 主题源：`src/data/theme.js`

## 1. 页面职责

| 职责 | 说明 |
|---|---|
| 列出 | 渲染 11 套配色，每行显示色块 + 名称 |
| 选择 | 点击某行 → `pick(item)` → 写存储 → 全站即时生效 |
| 预览 | 色块用底色 + 强调色双层，同时表达深浅与主色 |

配色构成：`classic`（应用原有的纯黑）为第 1 套，其余 10 套从 `ev/class-schedule` 移植，保证两个应用视觉语言一致。

## 2. 路由与入口

| 项 | 值 |
|---|---|
| 路由 | `pages/theme` |
| 文件 | `src/pages/theme/theme.ux` |
| 入参 | 无 |
| 上游 | 设置页「主题」条目 |
| 下游 | 返回设置页 |

## 3. 页面结构

```
div.page
├── 页头胶囊（后退 + 「主题」，与 pill / nickname / settings / cd-list 同构）
└── scroll (list, scroll-y)
    └── row × 11
        ├── sw  → 内嵌 dot，style 由 item.swatch / item.dot 提供
        └── nm  → 主题名，颜色取 item.text
```

**当前项标识不用文字**：168px 行宽放不下「4 字主题名 96 + 色块 34 + 「当前」48」，会折行。改用整行 2px 强调色描边表达选中态。

## 4. 数据与存储

| key | 说明 |
|---|---|
| 当前主题 key | 保存选中的主题标识，默认 `classic` |
| `theme` 对象 | 运行时展开为 `bg / card / cardLight / text / textSecondary / textMuted / accent / border` 等变量，页面样式统一引用 |

读取方：`cd-list`、`cd-edit`、`settings`、`nickname`、`diag` 全部通过 `data/theme.js` 取当前主题，**没有任何页面硬编码颜色**。

## 5. 交互规则

| 手势 | 位置 | 行为 |
|---|---|---|
| 点击 | 主题行 | `pick(item)` → 写入选中 key → 描边更新 → 其他页面下次 `onShow` 生效 |
| 点击 | 页头返回 | `goBack()` 回设置页 |
| 滑动 | 列表区 | 上下滚动（11 项必须滚动，见 §7） |

## 6. 状态与边界

| 状态 | 表现 |
|---|---|
| 未选择过 | 默认 `classic`，描边落在第 1 行 |
| 浅色主题（晨光白 / 暖阳米） | 文字色必须取 `item.text` 而非 `theme.text`（当前主题色），否则出现白字白底 —— 看起来像列表底部多出两个空白行。**这是 2026-11-02 真机反馈的真因，改动本页时必须守住** |
| 主题被删除/改名 | 存储里的旧 key 兜底回落 `classic` |

## 7. 平台约束（Vela 手环）

1. **必须可滚动**：11 项 × 50px ≈ 550px，远超 192×490 可视高度。不做分页 —— 分页会让「换主题」变成翻两次的操作。
2. 字号只走 `ev-six` 四档：**44 / 30 / 28 / 24**，不新增档位。
3. 色块用双层 `div`（外层底色、内层强调色点）实现，不引图片，避免 11 套各配一张资源。
4. 页头胶囊结构与 `pill` / `nickname` / `settings` / `cd-list` 保持一致，不另写一套。

- [ ] 每种主题下都能正常进入列表、编辑、设置，无低对比度到看不清的项
