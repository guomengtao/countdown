## 4. 权限用途说明（填表用）

`manifest.features` 共 7 项，逐条对应填表口径：

| feature | 用途（填表原话） | 触发时机 |
|---|---|---|
| `system.router` | 页面跳转（列表 ↔ 编辑 ↔ 设置 ↔ 主题） | 用户点击入口时 |
| `system.storage` | 保存倒数日条目、主题与版式偏好到本地 | 保存 / 切换时 |
| `system.prompt` | 删除、清空等危险操作的二次确认弹窗 | 用户点删除 / 清空时 |
| `system.device` | 读取屏幕形状与尺寸，胶囊屏改用方键键盘 | 进入输入页时 |
| `system.vibrator` | 操作反馈的轻微震动 | 保存成功、切换时 |
| `system.file` | 读取内置精简词库文件（中文输入候选词） | 进入标题输入页时 |
| `system.app` | 读取应用自身版本号用于诊断页 | 打开诊断页时 |

**统一口径**：以上能力均**不涉及网络、不上传数据、不读取用户其它文件**；`system.file` 只读取应用包内的词库资源。

⚠️ **决策点 2**：`permissions` 字段当前为 `null`。若目标商店要求显式声明（如「存储」「皮肤」），需在 `manifest.json` 补 `permissions` 数组——**这属代码改动，须与商店后台类目对齐后再动**。

## 5. 商店截图清单

要求：实机截图（非 IDE 预览），两类机型各一套；建议 4~6 张/机型。

| # | 页面 | 拍什么 | 判读点 |
|---|---|---|---|
| 1 | 应用列表 | 应用图标 | 蓝底 + 黄进度环 + 白 7，环形不被裁 |
| 2 | 首页（列表版式） | 3~5 条不同状态条目同屏 | 含「N 天」「0 天」「N 天前」三种文案；已结束有分隔线 |
| 3 | 首页（大字版式） | 单条放大的样子 | 数字最大、单位为「天后 / 天前」 |
| 4 | 编辑页 | 名称、模式、日期滚轮、配色 | 控件完整不溢出 |
| 5 | 主题页 | 三套主题色卡 | 深 / 浅 / 暖三色可辨 |
| 6 | 设置页 | 清空与诊断入口 | 二次确认有提示 |

机型：手环 9（192×490，方屏）+ 手环 11（212×520，胶囊屏）。胶囊屏重点看顶部圆角区不压字、底部按钮不被切。

## 6. 隐私说明要点（草稿）

```
本应用不收集、不上传任何个人信息。

· 你创建的倒数日条目、主题与版式偏好，仅保存在手环本地存储中。
· 应用不发起任何网络请求，无账号体系，无统计分析，无广告 SDK。
· 应用不读取手环上的其它应用数据；仅在隐藏输入框输入标题时读取内置词库文件。
· 卸载应用或清除应用数据，将同时删除全部本地记录，且不可恢复。
```

⚠️ **决策点 3**：是否需要提供「导出 / 备份」能力？当前无导出，清空即不可恢复——商店审核通常会问数据可携性，若无此功能，隐私声明里要写明「不提供云端备份」。
