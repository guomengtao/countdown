# 倒数日 · 输入法测试版 v0.0.30

> 给测试用户的说明。开发者核对信息在最末尾。

## 这不是成品，是一个「探针包」

里面没有任何倒数日功能。它只做一件事：**在你手上真实的手环上，测出中文输入法能不能用、哪种布局会崩**。

我们手上只有模拟器，而模拟器已经证明它和真机不一样。所以最终答案只能从你的手环上来。

## 操作步骤（约 2 分钟）

**第 1 步 · 打开看一眼**

应该看到「倒数日 / v0.0.30」和一个蓝色「诊断信息」按钮，下面是七行键盘名称。

**第 2 步 · 点「诊断信息」，截一张图**

确认页面上版本是 `0.0.30`。看到就说明包装完整了。**这张图先截下来存着**。

**第 3 步 · 返回，一行一行往下测**

每行的流程完全一样：

```
点「胶囊全键盘」 → 看到「加载键盘」按钮 → 点它
                → 键盘出来了吗？
                    出来了    → 随便敲几个键，再点左上角 ‹ 返回
                    没出来    → 闪退/黑屏/重启都没关系，重新打开应用接着测下一行
```

七行依次做完：

| 行 | 名称 | 它和上一行的区别 |
|---|---|---|
| 1 | 胶囊全键盘 | 基准款，完整键盘 |
| 2 | 矩形全键盘 | 换矩形布局引擎 |
| 3 | 圆形全键盘 | 换圆形布局引擎 |
| 4 | 胶囊九键 | 九宫格，键更少更大 |
| 5 | 精简词库 | 词库只留中文，包更小 |
| 6 | 矩形九键 | 矩形 + 九键组合 |
| 7 | 三候选 | 候选词只显示 3 个 |

**第 4 步 · 回首页看右侧标记**

- `✓` 绿色 —— 这一种键盘能用
- `×` 红色 —— 这一种加载后崩了
- `…` 灰色 —— 只打开了页面，键盘没加载

**第 5 步 · 再点「诊断信息」，截一张图发我**

这一张最关键，七种形态的结论都在上面。

## 请重点帮我确认三件事

1. **键盘最右边那一列键，看得见吗？**
   模拟器上右边被切掉了（`Q W E` 到 E 就断了）。真机是不是也这样，决定我们要不要改代码。

2. **点「加载键盘」之后，有没有闪退或自动重启？**
   记一下是哪个名称就行，不用描述现象。

3. **键盘上的字能看清吗？会不会太小或太挤？**

## 崩了不用慌

闪退、黑屏、自动重启都不会弄坏手环，也不会丢数据。重新打开应用，之前测过的记录还在，接着往下测。

## 本轮改动（ev-six 合规）

三个页面全部重做，字号只保留 **44 / 30 / 28 / 24** 四档，最小 24px：

| 页面 | 改动 |
|---|---|
| index | A–G 字母格子改成七行形态名；标题 44px；去掉折行因素（`v0.0.30` 本身已占满 7 字符位，再加「已测 N 个」必然折行顶出屏幕） |
| exp | 返回键从 19px 纯文字改为 **48×48 独立热区**；`.hd` 加 `flex-shrink: 0` |
| diag | 结果行改为左右两栏；去掉 `→` 和 `·` |

**「输入一半返回失效」的根因**：`.hd` 没有 `flex-shrink: 0`，键盘加载后子元素总高超过屏幕高度，flex 把整个页头压缩到接近 0 高度——返回按钮不是"小"，是被挤没了。同时原热区仅 38×19，本身也点不中。

## 已知未修：键盘右侧溢出

| 形态 | screentype | 键盘 | 模拟器表现 |
|---|---|---|---|
| A 胶囊全键盘 | pill-shaped | QWERTY | 能加载，右侧溢出被裁 |
| B 矩形全键盘 | rect | QWERTY | 能加载，右侧溢出被裁 |
| C 圆形全键盘 | circle | QWERTY | 未单独验证 |
| D 胶囊九键 | pill-shaped | T9 | 未单独验证 |
| E 精简词库 | pill-shaped | QWERTY | 未单独验证 |
| F 矩形九键 | rect | T9 | 未单独验证 |
| G 三候选 | pill-shaped | QWERTY | 未单独验证 |

组件内部按 **480px 画布**绝对定位键位，手环 10/11 为 212 宽、手环 9 为 192 宽，模拟器上横向溢出约 2.26 倍。

**关键待验证**：课程表与本包使用**完全相同的 `config.designWidth = "device-width"` 和同一个输入法组件**，而课程表在真机手环 10 上中文输入可用。若真机把 480 画布正确映射到屏宽，则模拟器的溢出属模拟器缺陷，真机应正常；若真机同样溢出，则需给键盘加缩放层（`config.designWidth` 改 480 或容器 `transform: scale`，两条路都试过，后者在模拟器上有效但需精调比例）。
