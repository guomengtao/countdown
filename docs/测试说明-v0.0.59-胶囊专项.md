# 测试说明 v0.0.59 · 胶囊键盘专项

> 这一版只做一件事：**验证手环 11 的胶囊屏到底能不能用胶囊布局的输入法。**
> 全程大约 2 分钟，只需要点 2 下。

---

## 为什么又发一次

之前测出「只有矩形键盘能打开」，但别人做的应用（比如「英汉互译」）在 11 上输入法是正常的。

说明**组件本身没问题，是我们调用它的方式有问题**。

这一版把调用方式改成最简结构，并且在页面上把设备真实参数打出来了，一次就能定位。

## 我需要判断的三种结果

| 你看到的 | 说明什么 | 下一步 |
|---|---|---|
| 键盘出来了，是圆键 | 胶囊布局可用，之前是调用方式错了 | 直接改版本，用胶囊布局 |
| 键盘出来了，但是方键 | 说明还是走了矩形布局 | 查参数有没有传进去 |
| 白屏 / 闪退 | 胶囊布局在 11 上确实跑不起来 | 只能退回矩形方案 |
| 第一次能开、第二次崩 | 撞上官方已知 bug | 改用「只保留一个键盘页」的结构规避 |

## 这一版和上一版的差别（技术细节，可以跳过）

1. **页面结构改成最简**——去掉所有装饰性容器，只留「标题 + 一行设备信息 + 输入框 + 键盘」
2. **键盘改为立即加载**——不再延迟 800ms
3. **把 `device.getInfo` 的返回值直接显示在屏幕上**（屏宽 / 高 / 屏幕形状）

第 3 条是关键：如果那行显示 `屏宽 212`，说明设备信息读取正常，问题不在参数；如果显示别的数字，问题就定位了。
