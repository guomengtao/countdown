# 测试说明 v0.0.67 · 两个输入页对照

> 这一版把「胶囊键盘」改成正式功能「设置科目」，和「设置昵称」走同一套流程。
> **两个入口用的是两种不同的键盘布局**，正好一次装包就能对比。

---

## 首页应该长这样

```
倒数日
v0.0.67
[ 还没设置昵称 ]
科目未设置
[  设置昵称  ]   蓝
[  设置科目  ]
[  诊断信息  ]
```

---

## 需要测三件事

### 1. 点「设置昵称」→ 用方键键盘输一个名字 → 保存

返回首页应看到名字显示在上面的框里。

### 2. 点「设置科目」→ 用圆键键盘输一个科目 → 保存

返回首页应看到 `科目 xxx`。

这个页面顶部有一行 `屏宽212 胶囊`，**这行请连同键盘一起截图**。

### 3. 两个都进去过之后，再各点一次

看第二次进去还能不能打开。（官方有个未修复的 bug：键盘页第二次进入可能崩）

---

## 两个页面的区别（这就是测试目的）

| | 设置昵称 | 设置科目 |
|---|---|---|
| 键盘形状 | 方键 | **圆键** |
| 布局类型 | `rect` | **`pill-shaped`** |
| 键盘加载 | 延迟 300ms | 立即加载 |

**如果「设置科目」能打字、能保存、首页能显示**，就说明胶囊布局彻底通了，后面倒数日正式版就用它。

---

## 四种结果对应四种走法

| 你看到的 | 结论 |
|---|---|
| 两个都能用 | 胶囊布局确认可用，正式版走 pill |
| 科目页白屏 / 闪退 | 胶囊布局在真机确实不行，退回 rect |
| 科目页能开但打不出字 | 键盘渲染了但回调没通，查事件绑定 |
| 第一次能开、第二次崩 | 撞上官方已知 bug，改成单键盘页结构规避 |
