# 测试说明 v0.0.80（真机 11 · 键盘不显示排查版）

安装包：`com.application.watch.countdown.release.0.0.80.rpk`

## 这一版要解决什么

上一版（0.0.70）在手环 11 上：页头、屏宽文字、输入框、保存按钮都正常显示，
**只有键盘不出来，也不崩溃**。同样页面在模拟器 212×520 上键盘是出的。

怀疑：键盘组件是「贴父容器底部」定位的，父容器高度在真机上算不出来（算成 0），
键盘就被排到看不见的位置。这一版把父容器从「自动（flex）」改成「写死的四档」，
一次安装就能试完四个假设。

## 怎么测（重点：一次装完能测四档）

1. 打开「倒数日」→ 点「设置科目」
2. 页面打开时默认就是**第 4 档**（最可能出键盘的布局），先看键盘出不出来
3. 如果出了 → 直接输入几个字，点「保存」，回首页看「科目 xxx」
4. 如果没出 → 点屏幕第二行右侧的**橙色圆形数字按钮**，按 4→1→2→3 循环换档，每换一档看一眼键盘

四档分别代表：

| 档位 | 键盘容器 | 含义 |
|---|---|---|
| 4 | 铺满整屏（绝对定位） | 完全不靠布局计算，键盘必然贴屏幕底（默认档） |
| 1 | 250px | 和 0.0.70 版等价（真机不出） |
| 2 | 330px | 中等 |
| 3 | 400px | 接近整屏 |

判读：

- **4 档能出、1~3 不出** → 确认是高度问题，下一版直接定死全屏方案
- **四档都不出** → pill 形状键盘在真机 11 上根本渲染不了，下一版改用方键（rect，昵称页验证过能出）

## 顺带确认两件事

第二行会显示 `212×520`（机器上报的屏宽×屏高），确认是这两个数。

保存后回首页，看「科目 xxx」有没有显示。

## 测完告诉我

1. 键盘在第几档出现的（或者一直没出现）
2. 第二行显示的屏宽×屏高
3. 保存后首页有没有显示科目
