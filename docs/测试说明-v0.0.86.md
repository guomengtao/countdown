# 测试说明 v0.0.86

日期：2026-11-01

## 本版修了什么

### 1. 设置科目页「点了没反应」——已定位并修复

**根因**：键盘容器是 `position:absolute; left:0; top:0; width:100%; height:100%`，
**整屏铺满**，而且排在页头和按钮之后。它是一层透明的大盖子，
在真机上 `z-index` 拦不住它，于是：

- 顶部返回胶囊 → 点到的是盖子
- 档位按钮（显示 4 的那个）→ 点到的是盖子
- 输入框 → 点到的是盖子
- 保存 → 点到的是盖子

四处全废，与你反馈的「4 个地方点击无效」完全对上。

**改法**：容器不再从 `top:0` 铺满，改成贴底 `bottom:0; height:336px`。
内容区实测到底 y≈154，容器从 y=184 开始，上方 30px 完全不覆盖。
键盘在组件内部仍是 `bottom:0`，所以位置不变、还是贴屏幕底。

> 模拟器上已确认修好：点档位按钮，数字从 4 变成 2，页面有响应。

### 2. 四个按钮热区放大

| 控件 | 原尺寸 | 现尺寸 |
|---|---|---|
| 返回胶囊 | 140×40 | **160×48**（圆角 24，字号 24→28） |
| 档位按钮 | 52×44 | **68×52**（字号 24→30） |
| 输入框 | 104×40 | 100×44 |
| 保存 | 72×40 | **76×44** |

手环是手指点，48 是下限，40 高实测点不准。

### 3. 新图标「不生效」

查过包：`logo.png` 在 rpk 里的 SHA256 与源码新图标**完全一致**（`5ba7b114...`），
包里就是新图。看不到变化是**设备端图标缓存**，应用列表会按包名缓存图标。

**处理办法（二选一）**：

- 长按应用 → 卸载 → 重新安装本版
- 或重启手环后再看

如果卸载重装还是旧图，请拍一张应用列表的照片给我，我再查是否要换 192×192。

## 测试步骤（约 1 分钟）

1. 先按上面的办法重装，看一眼**应用列表图标**是不是蓝底黄圈「7」
2. 打开应用 → 首页应为：倒数日 / v0.0.86 / 还没设置昵称 / 科目未设置 / 三个按钮（设置科目是蓝色主按钮）

6. 在键盘上敲两个字 → 点保存 → 回首页看「科目」后面有没有显示
