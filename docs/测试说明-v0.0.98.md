# 倒数日 v0.0.98 测试说明

**包**：`com.application.watch.countdown.release.0.0.98.rpk`
**本版改动**：设置科目页的档位切换从「一个循环按钮」改为 **4 个独立按钮**，点哪个进哪档。

---

## 一、这次只需测一个页面

首页 → 点蓝色「设置科目」→ 依次点 1 / 2 / 3 / 4 四个按钮，看每一档键盘出不出。

| 按钮 | 键盘容器高度 | 含义 |
|---|---|---|
| 1 | 250px | 最矮，最可能不出键盘 |
| 2 | 330px | 中等 |
| 3 | 400px | 接近整屏 |
| 4 | 绝对定位贴底 336px | 默认档，最可能出键盘 |

**选中态是橙色**，未选中是深灰。点完看颜色有没有跟着切换——这同时验证了热区是否生效（上一版四处点击全部失效，根因是一层整屏透明容器把点击吃掉了，本版已修）。

## 二、判读规则

- **某一档出键盘** → 记下是几，下版把这个高度定死
- **四档都不出** → 说明 pill-shaped 胶囊键盘在真机 11 上根本渲染不了，下版直接换 rect 方键（昵称页已验证可用），不再耗你的测试机会
- **按钮点了颜色不变** → 说明热区仍未通，请回报是哪个按钮

## 三、顺带看两件事

1. **顶部返回胶囊**（‹ 设置科目）：点一下能否回到首页
2. **图标**：应用列表里图标与下方名称之间还有没有压字。本版图标已裁掉透明边，占位从 128 降到 100

## 四、需要回报的信息

1. 几档出键盘、几档不出
2. 按钮点击有没有反应（颜色变化）
3. 返回胶囊是否有效
4. 图标还压不压名字

---

## 已知问题（不用重复报）

**键盘最下面一行被屏幕底部弧边裁掉约 20px**。这是高度预算冲突：屏幕 520，顶部内容区（返回胶囊 + 分辨率 + 4 个档位按钮 + 输入框与保存）占 180px，键盘容器只剩 336px，而完整键盘需要约 358px。Z / X 那一行虽然显示不全，但仍可点击。

如果确认第 4 档键盘可用，下一版会删掉「212×520」那行诊断文字（省 24px），把空间让给键盘。
