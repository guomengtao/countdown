# 倒数日手环快应用 v0.0.99 测试说明

日期：2026-11-02　模拟器：ctd-cd-b（手环9 尺寸 192×490）

## 本版改了什么

1. **「设置昵称」页头统一成「设置科目」页头**
   - 原来是左上角小方块 `‹` + 单独一行标题，两行占 106px
   - 现在是一个居中胶囊：`< 设置昵称`，图标是 lucide chevron-left 转的 PNG（light 白描边版），
     整块 160×48 都可点返回，和科目页完全同构（同一套 `.top` / `.hd` / `.hd-ic` / `.hd-t` 样式）
   - 顺带省出 46px 高度给键盘

2. **首页支持右划进入「设置科目」**
   - 双通道：Vela 的 `onswipe`（direction=right）+ `touchstart/touchend` 位移判定（dx>60、dy<60、<800ms）
   - 两个通道都会命中，用 `navAt` 800ms 去重，不会连开两页
   - 首页加了一行小字提示「右划进入科目」（24px，6 字 144px，192 宽不贴边）

3. **科目页腾高度：删掉屏宽诊断行**
   - 490 屏上那 26px 直接决定键盘能不能整块出来；屏宽×屏高改到「诊断信息」页看
   - 键盘容器高度不再写死 336，改成 `屏高 - 158`（顶部胶囊 60 + 档位行 48 + 输入行 46 + 间隙 4）
     - 手环 11/10（520）→ 362px
     - 手环 9（490）→ 332px
   - 四档按钮 44→42 宽、间距 6→3（4×42+3×3=177，192 屏居中，实测橙色块 x∈[144,185] 未被裁）

### 裁切原因（不是布局 bug）

输入法组件内部按键尺寸按 212 宽 / 520 高的机器排的，
QWE 全键盘竖排需要约 358~380px 高、横排需要约 212px 宽。
手环 9 只有 192×490，扣掉页头（158px）只剩 332px 高、192 宽，必然裁。

**11/10（212×520）扣掉页头后有 362px 高、212 宽**——本版删掉诊断行 + 动态算高就是为了这一档，
理论上能整块放下（待真机 11 验证）。
