# 倒数日手环快应用 v0.6.3 测试说明

日期：2026-11-02　版本：**0.6.3 / versionCode 142**　包：`com.application.watch.countdown`

上一份测试说明是 `测试说明-v0.0.99.md`。之后到 0.6.3 之间首页做过一次大改（重做为 iOS「倒数日」风格的双版式列表、加主题、加正计时、清掉课程表遗留页），

## 本版改了什么（0.6.1 → 0.6.3 三次提交）

| 版本 | 提交 | 改动 | 用户可见 |
|---|---|---|---|
| 0.6.1 | `a255446` | 过期条目不再显示负号，改「5 天前」 | 是 |
| 0.6.2 | `ee224e9` | 天数方向统一由单位承担：正计时去掉 `+` 号，也显示「N 天前」；删掉 `phrase`/`dirWord` 死字段 | 是 |
| 0.6.3 | `ad96b13` | 应用图标恢复第一版环形样式（蓝底 + 黄进度环 + 白数字 7），尺寸保持 100×100 | 是（图标） |

为什么废掉正负号：① bold 字重下 ASCII hyphen 会被渲染成长横，`-5` 看起来像「一5」（真机实测）；
② `+` 直觉指向未来，但正计时表示的是「已经过去 N 天」，语义反了。现在方向全部由单位「天 / 天前」承担。

## 首页天数判读规则（本版核心验收点）

| 情形 | 数字 | 单位（列表版式） | 单位（大字版式） | 颜色 | 位置 |
|---|---|---|---|---|---|
| 目标在未来 | `126` | 天 | 天后 | 用户自选色 | 「已结束」分隔线之上 |
| 就是今天 | `0` | 天 | 天 | 用户自选色 | 同上 |
| 目标已过期（倒数） | `5` | **天前** | **天前** | **压灰**（theme.textMuted） | 「已结束」分隔线之下 |
| 正计时（mode=up） | `306` | **天前** | **天前** | 用户自选色（**不压灰**） | 分隔线之上 |

判错的样子：出现 `+306`、`-5`、今天显示成「0 天前」、正计时被压灰或被塞进「已结束」分组。

## 自动化已覆盖的部分

`npm test`（`test/decorate.test.js`，47 项，纯 node，不需要模拟器/手环）：

- 四种情形的主文案（含正计时当天 = 今天）；
- 铁律：`numText` 永不带 `+` / `-` / `−`；
- 字号三档：≤2 字符 44px、3 字符 30px、≥4 字符 28px（越界会在真机折行，0.5.7 踩过）；
- 真跑一遍 `sortForDisplay` 再判分组：active 全在前、done 全在后，分隔线只在组首出现一次；
- 进度条像素：无日期钳到 4px、半程 72 / 74px；
- `phrase`、`dirWord` 不许复活（源码与模板双向检查）。

测法是把 `.ux` 里真实的 `decorate()` 源码抽出来求值，再给 `@system.storage` 打桩后 require 真实数据层——
不是抄副本，所以代码改了测试会跟着改。已做变异验证：把「天前」改回「天」，用例确实变红（2 项失败）。

### 未能验证的三态（今天 / 已过期 / 正计时）

这三态需要造数据，两条路都堵了：

1. **编辑页除页头外不吃 tap**：`vela tap` 点「倒数（模式切换）」与日期滚轮均无响应（画面采样值恒 5028），无法从 UI 新建条目；
2. **注入探针包会白屏**：在 `/tmp` 副本里把 `loadList()` 的 `items` 换成 4 条硬编码样本（未来/今天/已过期/正计时），构建后 `vela push` → **非零采样 = 0，白屏**；推回正式包立刻恢复，实例无损。原因未定位，已记坑。

所以「0 天」「N 天前」两个分支**目前只有单测保证**（`npm test` 里四条文案用例 + 分组用例），**缺真机像素证据**——这正是上面验收清单第 3~6 项要补的。

## 已知风险 / 未验

1. **三态缺真机像素证据**：见上节。0.6.1~0.6.3 三次改动均未经过完整人眼验收，上面 12 项就是补这一课。
2. **同版本重装历史同名**：历史记录按 `<应用>-<版本>-vc<N>.rpk` 命名，重复投同一版本无法从文件名区分批次，要精确追溯得先 bump。
3. **签名文件不入库**：`sign/private.pem`、`sign/certificate.pem` 缺失时报 `certification path` error，换机器要单独拷。
4. **上架物料未准备**：无商店截图、简介、隐私政策、更新日志；`permissions` 为 `null` 而 `features` 用了 `system.file` / `system.storage` / `system.vibrator`，填表时需说明用途。
