# 页头返回按钮规范（2026-11-01 定稿，设置科目页首用）

## 一、形态

返回键与页面标题合并成**一个整体按钮**，位于**顶部水平居中**，形如 `< 设置科目`：

```
┌──────────────┐
│ ‹  设置科目  │   ← 148×40，圆角 20，底色 #3a3a3c，整块可点返回
└──────────────┘
```

- 不再拆成「左上角方块返回键 + 右侧标题」两段。之前那样做，212 宽下标题被挤、返回键容易被
  胶囊弧边切掉，且点击区只有 48×48，真机手指点不中。
- 点击区 = 整个胶囊，比单图标大一倍以上。

## 二、图标：lucide PNG 双版本，不用 icon font

- 来源：<https://lucide.dev/icons/chevron-left>（lucide-static v1.66.0，ISC 许可）
- 手环缺字形，`‹`、`‹` 之类的字符在不同机型上会变方框，**禁止用文字/icon font 当图标**。
- Vela 的 `image` 不支持 tint（无法给单张图染色），所以同一图标要出**两张 PNG**：
  - `src/common/icons/chevron-left-light.png` —— 白色描边（深色界面用，当前默认）
  - `src/common/icons/chevron-left-dark.png` —— 深色描边（浅色界面备用）
- 生成方式（可复现）：

```bash
curl -sL -o /tmp/chevron-left.svg https://unpkg.com/lucide-static@latest/icons/chevron-left.svg
sed 's/currentColor/#ffffff/' /tmp/chevron-left.svg | rsvg-convert -w 96 -h 96 -o chevron-left-light.png
sed 's/currentColor/#1c1c1e/' /tmp/chevron-left.svg | rsvg-convert -w 96 -h 96 -o chevron-left-dark.png
```

- 96×96 是 24pt 图标的 4 倍图，页面上按 20×20 显示，缩放不发虚。
- 放在 `src/common/icons/`，引用写绝对路径 `/common/icons/xxx.png`（与 ev 课程表同一惯例）。
  `src/assets/` 下不要放同名副本，会重复打进包。

## 三、实现（pages/pill/pill.ux）

```html
<div class="hd" onclick="goBack">
  <image class="hd-ic" src="/common/icons/chevron-left-light.png"></image>
  <text class="hd-t">设置科目</text>
</div>
```

```css
.page { flex-direction: column; align-items: center; }
.hd {
  width: 148px; height: 40px; flex-shrink: 0;
  margin-top: 26px; border-radius: 20px; background-color: #3a3a3c;
  flex-direction: row; justify-content: center; align-items: center;
}
.hd-ic { width: 20px; height: 20px; margin-right: 2px; object-fit: contain; }
.hd-t  { font-size: 24px; color: #ffffff; lines: 1; }
```

要点：

1. `flex-shrink: 0` 必须写。键盘撑高后页头会被压成 0 高 —— 这是「返回键消失」的历史坑，别再踩。
2. `margin-top: 26px`：胶囊屏四角弧半径≈屏宽一半（212 屏 = 104），贴顶会被弧边切掉。
3. 字号 24 是 ev-six 最小档；`设置科目` 四字 + 箭头 + 圆角内边距 = 148 宽，212 屏单行放得下。
4. `.page` 改成 `align-items: center` 后，下面的输入框/保存按钮自动居中，左右各留 30，与原左对齐视觉一致。
