## 六、发布前必须解决：先有资源页

发布器（Ev Publisher）当前只支持**更新已有资源页**，不支持新建。所以首发这一帖必须二选一：

| 方式 | 步骤 | 备注 |
|---|---|---|
| **A. 手工建帖（推荐）** | 浏览器打开 `https://www.bandbbs.cn/resources/categories/95/add` → 选 `download_external` → 填标题/简介/正文 → 传 8 张图 → 外链填 GitHub Release 直链 → 发布 | 拿到资源 ID 后回填台账，之后所有更新都能在发布器里一键发 |
| B. 走发布器新建能力 | 需要先给 `ev-publisher` 加「建帖」流程（现无） | 属于二期，本期不做 |

**外链前置**：`guomengtao/countdown` 是 public，但**还没有任何 Release**。需要先打一个：

```bash
gh release create v0.6.12 \
  /Users/Banner/Documents/guomengtao/ev/countdown/dist/com.application.watch.countdown.release.0.6.12.rpk \
  -R guomengtao/countdown -t "Ev倒数日 0.6.12" -n "首个公开预览版"
```

打好后外链为：
`https://github.com/guomengtao/countdown/releases/download/v0.6.12/com.application.watch.countdown.release.0.6.12.rpk`

## 八、权限与隐私口径（填表用）

`manifest.features` 共 7 项，全部**不联网**：

| feature | 用途（填表原话） | 触发时机 |
|---|---|---|
| `system.router` | 页面跳转（列表 ↔ 编辑 ↔ 设置 ↔ 主题） | 用户点击入口时 |
| `system.storage` | 保存倒数日条目、主题与版式偏好到本地 | 保存 / 切换时 |
| `system.prompt` | 删除、清空等危险操作的二次确认弹窗 | 用户点删除 / 清空时 |
| `system.device` | 读取屏幕尺寸，胶囊屏改用方键键盘 | 进入输入页时 |
| `system.vibrator` | 操作反馈的轻微震动 | 保存成功、切换时 |
| `system.file` | 读取应用包内的精简词库（中文输入候选词） | 进入标题输入页时 |
| `system.app` | 读取应用自身版本号，用于诊断页 | 打开诊断页时 |

`permissions` 字段当前为 `null`——若米坛要求显式声明再补，属代码改动。

